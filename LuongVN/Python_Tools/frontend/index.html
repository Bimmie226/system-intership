HƯỚNG DẪN

Trước khi triển khai

  1. Kiểm tra resource

    Khai báo apiVersion, kind và metadata.name trong mỗi document.

  2. Chọn namespace

    Đặt metadata.namespace trong YAML. Resource có namespace sẽ dùng default nếu bỏ trống.

  3. Xem kết quả

    Mỗi resource được backend áp dụng sẽ xuất hiện trong bảng bên dưới.

Namespace phải tồn tại trước khi áp dụng resource vào namespace đó.
