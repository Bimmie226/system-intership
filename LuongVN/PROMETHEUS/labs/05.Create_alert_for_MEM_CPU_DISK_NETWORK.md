# Thực hành tạo 1 số alert về RAM, CPU, DISK, NETWORK 

## I. CPU 

- Rule cơ bản: 

```yaml 
- alert: NodeCPUHigh
  expr: |
    100 - (
      avg by (instance) (
        rate(node_cpu_seconds_total{mode="idle"}[5m])
      ) * 100
    ) > 80
  for: 10m
  labels:
    severity: warning
    resource: cpu
  annotations:
    summary: "High CPU usage on {{ $labels.instance }}"
    description: "CPU usage has been above 80% for 10 minutes."
```

- Critical: 

```yaml
- alert: NodeCPUHighCritical
  expr:
    100 - (avg by (instance) (rate(node_cpu_seconds_total{mode="idle"}[1m])) * 100) > 90
  for: 1m
  labels:
    severity: critical
    resource: cpu
    namespace: monitoring
    lab: alert-rule
  annotations:
    summary: "High CPU usage on {{ $labels.instance }}"
    description: "CPU usage has been above 90% for 1 minute!"
```

## II. RAM 

- warning: 

```yaml
- alert: NodeMemoryLow
  expr: |
    (
      node_memory_MemAvailable_bytes
      /
      node_memory_MemTotal_bytes
    ) * 100 < 15
  for: 10m
  labels:
    severity: warning
    resource: memory
  annotations:
    summary: "Low available memory on {{ $labels.instance }}"
    description: "Available memory is below 15% for 10 minutes."
```

- Critical: 

```yaml 
- alert: NodeMemoryLowCritical
  expr: |
    (
      node_memory_MemAvailable_bytes
      /
      node_memory_MemTotal_bytes
    ) * 100 < 8
  for: 5m
  labels:
    severity: critical
    resource: memory
  annotations: 
    summary: "Low available memory on {{ $labels.instance }}"
    description: "Available memory is below 8% for 5 minutes."
```

## III. Disk 

### 3.0 Capacity

- warning: 

```yaml
- alert: NodeDiskSpaceLow
  expr: |
    (
      node_filesystem_avail_bytes{
        fstype!~"tmpfs|overlay|squashfs"
      }
      /
      node_filesystem_size_bytes{
        fstype!~"tmpfs|overlay|squashfs"
      }
    ) * 100 < 15
  for: 15m
  labels:
    severity: warning
    resource: disk
```

- Critical: 

```yaml
- alert: NodeDiskSpaceCritical
  expr: |
    (
      node_filesystem_avail_bytes{
        fstype!~"tmpfs|overlay|squashfs"
      }
      /
      node_filesystem_size_bytes{
        fstype!~"tmpfs|overlay|squashfs"
      }
    ) * 100 < 8
  for: 10m
  labels:
    severity: critical
    resource: disk
```

### 3.1 Prediction

```yaml
- alert: NodeDiskWillFillIn24Hours
  expr: |
    predict_linear(
      node_filesystem_avail_bytes{
        fstype!~"tmpfs|overlay|squashfs"
      }[6h],
      24 * 3600
    ) < 0
  for: 15m
  labels:
    severity: warning
    resource: disk
  annotations:
    summary: "Filesystem predicted to fill within 24h"
    description: "{{ $labels.instance }} {{ $labels.mountpoint }} may fill within 24 hours."
```

## IV. Network

- Network error: 

```yaml 
- alert: NodeNetworkReceiveErrors
  expr: |
    rate(
      node_network_receive_errs_total{
        device!~"lo|veth.*|docker.*|cali.*"
      }[5m]
    ) > 0
  for: 10m
  labels:
    severity: warning
    resource: network
```

- Network Drop:

```yaml
- alert: NodeNetworkReceiveDrops
  expr: |
    rate(
      node_network_receive_drop_total{
        device!~"lo|veth.*|docker.*|cali.*"
      }[5m]
    ) > 0
  for: 10m
  labels:
    severity: warning
    resource: network
```
