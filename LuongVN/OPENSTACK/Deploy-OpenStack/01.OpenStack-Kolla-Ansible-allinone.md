# Deploy OpenStack Kolla Ansible all-in-one

## Host machine requirements 

Cấu hình tối thiểu: 

- 2 network interfaces 
- 8GB MEM 
- 40GB DISK 

## Install dependencies 

1. Update the package 

```bash
sudo apt update 
```

2. Install Python 

```bash
sudo apt install git python3-dev libffi-dev gcc libssl-dev libdbus-glib-1-dev
```

### Install dependencies for the virtual environment 

1. Create lab dir

```bash
mkdir Openstack-kolla-ansible
cd Openstack-kolla-ansible
```

2. Install the virtual environment dependencies 

```bash
sudo apt install python3-venv
```

3. Create a virtual environment 

```bash
python3 -m venv /path/to/venv
source /path/to/venv/bin/activate
```

4. Install latest version of pip 

```bash
pip install -U pip
```

## Install Kolla-ansible 

1. Install kolla-ansible and its dependencies using pip 

```bash
pip install git+https://opendev.org/openstack/kolla-ansible@master
```

2. Create the `/etc/kolla` directory 

```bash
sudo mkdir -p /etc/kolla
sudo chown $USER:$USER /etc/kolla
```

3. Copy `globals.yml` and `passwords.yml` to `/etc/kolla` directory.

```bash
cp -r /path/to/venv/share/kolla-ansible/etc_examples/kolla/* /etc/kolla
```

4. Copy `all-in-one` inventory file to the current directory.

```bash
cp /path/to/venv/share/kolla-ansible/ansible/inventory/all-in-one .
```

## Install Ansible Galaxy requirements 

Install Ansible Galaxy dependencies: 

```bash
kolla-ansible install-deps
```

## Prepare initial configuration 

### Inventory 

Bước tiếp theo là chuẩn bị inventory file - là một tệp ansible trong đó ta chỉ định các máy chủ và các nhóm mà chúng thuộc về. Ta có thể sử dụng tệp này để định nghĩa vai trò của các node và access credentials 

Kolla Ansible có inventory file cho `all-in-one` và `multinode`, `all-in-one` cho phép triển khai 1 node OpenStack duy nhất trên localhost 

### Kolla passwords 

Mật khẩu được sử dụng trong quá trình triển khai được lưu trữ trong `/etc/kolla/passwords.yml`. Tất cả các mật khẩu trong tệp này đều trống và phải được điền thủ công hoặc bằng cách sử dụng trình tạo mật khẩu ngẫu nhiên:

```bash
kolla-genpwd
```

### Kolla globals.yml 

`globals.yml` là file config chính cho Kolla Ansible và được đặt mặc định ở `/etc/kolla/globals.yml`. Có 1 vài options cần thiết để triển khai Kolla Ansible: 

- Image options: 

    Người dùng cần chỉ định các image sẽ được sử dụng cho quá trình triển khai. Trong bài này, ta sử dụng các image được dựng sẵn, cung cấp trên [Quay.io](https://quay.io/organization/openstack.kolla). 

    Kolla cung cấp các container image dựa trên 1 số bản phân phối Linux: 

    - Debian (`debian`) 
    - Rocky (`rocky`) 
    - Ubuntu (`ubuntu`) 

    **Ví dụ:** 

    ```yaml 
    kolla_base_distro: "rocky"
    ```

- AArch64 options

    Kolla cung cấp image cho cả kiến trúc x86-64 và aarch64. Các image này không hỗ trợ nhiều kiến trúc trong cùng 1 tag (multiarch), vì vậy người dùng aarch64 cần thiết lập `openstack_tag_suffix`: 

    ```yaml 
    openstack_tag_suffix: "-aarch64"
    ```

- Networking: 

    Kolla-Ansible yêu cầu thiết lập một số tùy chọn mạng để xác định Card mạng nào dùng để quản lý OpenStack, card mạng nào kết nối máy ảo ra mạng ngoài, và IP nào dùng để truy cập các dịch vụ OpenStack 

    - `network_interface`: card mạng phục vụ quản lý 
      - Đây là card mạng trên host mà kolla dùng mặc định cho lưu lượng quản lý, chẳng hạn giao tiếp giữa các dịch vụ và giữa các node OpenStack 

        ```yaml
        network_interface: "ens3"
        ```

      - **Ví dụ:** Máy `controller-01` có card `ens160`, địa chỉ `192.168.1.10/24` dùng cho mạng quản lý thì ta đặt: `network_interface: "ens160"`

    - `neutron_external_interface`: card mạng nối máy ảo ra mạng ngoài 
      - Card này được Neutron kết nối vào bridge mạng ngoài, giúp lưu lượng của máy ảo đi tới mạng bên ngoài OpenStack 

        ```yaml 
        neutron_external_interface: "ens8"
        ```

      - Trong mô hình 2 card này: 
        - Card `ens8` phải ở trạng thái `UP`
        - Không gán IP trực tiếp lên card `ens8` trên host 
    - `kolla_internal_vip_address`: IP ảo để truy cập dịch vụ OpenStack 
      - Đây là 1 IP riêng, chưa được thiết bị nào sử dụng, nằm cùng subnet với mạng quản lý trong mô hình này 

        ```yaml 
        kolla_internal_vip_address: "192.168.70.250"
        ```

      - Keepalived quản lý IP ảo này. Trong cụm có nhiều controller và cấu hình HA phù hợp, IP có thể chuyển sang controller khác khi node đang giữ IP gặp sự cố. Nhờ vậy, các endpoint vẫn có một địa chỉ truy cập chung.
- Bật các dịch vụ bổ sung: 
  - Mặc định, Kolla-Ansible cung cấp bộ dịch vụ cơ bản, đồng thời hỗ trợ nhiều dịch vụ bổ sung. Để bật 1 dịch vụ, đặt tùy chọn `enable_*` tương ứng thành `true`
- Sử dụng nhiều tệp globals
  - Ta có thể tách tùy chọn trong `globals.yml` thành nhiều tệp yaml 
  - Tạo thư mục `/etc/kolla/globals.d` và đặt các tệp yaml vào đó. 

## Deployment 
Kolla-Ansible cung cấp một playbook để cài đặt tất cả các dịch vụ cần thiết với phiên bản phù hợp.

Các lệnh dưới đây giả định sử dụng inventory `all-in-one`. Nếu sử dụng inventory khác, chẳng hạn `multinode`, hãy thay đổi đối số `-i` tương ứng.


1. Bootstrap các server để cài đặt dependencies cần thiết cho Kolla deployment: 

    ```bash
    kolla-ansible bootstrap-servers -i ./all-in-one
    ```

2. Thực hiện các kiểm tra trước deployment trên các host: 

    ```bash
    kolla-ansible prechecks -i ./all-in-one
    ```

3. Thực hiện deployment OpenStack: 

    ```bash
    kolla-ansible deploy -i ./all-in-one
    ```
