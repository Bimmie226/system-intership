# Cài đặt ArgoCD 

## I. Cài đặt 

```bash
kubectl create namespace argocd 
kubectl apply -n argocd --server-side --force-conflicts -f https://raw.githubusercontent.com/argoproj/argo-cd/stable/manifests/install.yaml
```

- `--server-side`: Một số CRD của ArgoCD, chẳng hạn như AplicationSet có kích thước vượt quá giới hạn annotation 262KB mà kubectl apply phía client. Server-side apply tránh được giới hạn này vì nó không lưu annotation last-applied-configuration.
- `--force-conflicts`: cho phép thao tác apply giành quyền quản lý đối với các field trước đó có thể đã được quản lý bởi những công cụ khác, chẳng hạn như Helm hoặc một lần chạy kubectl apply trước đó.

## II. Cài đặt ArgoCD CLI 

```bash
curl -sSL -o argocd-linux-amd64 https://github.com/argoproj/argo-cd/releases/latest/download/argocd-linux-amd64
sudo install -m 555 argocd-linux-amd64 /usr/local/bin/argocd
rm argocd-linux-amd64
```
